# Why it misses
They keep types DRY, enforce consistency with a single source, and prevent manual types from drifting out of sync with the real data.

<Steps>
  <Step icon="box" title="Partial<T>">
    Makes all properties optional. Use for <Kw>update payloads</Kw> where you only send the fields you want to change.
  </Step>
  <Step icon="flag" title="Pick<T, K>">
    Extracts only the listed keys. Use for <Kw>read models</Kw> — a card preview needs title and slug, not the full entity.
  </Step>
  <Step icon="key" title="Omit<T, K>">
    Removes specific keys. Use when a derived type should have <em>everything except</em> a field — like a <Kw>create input</Kw> that doesn't include an auto-generated ID.
  </Step>
  <Step icon="check" title="The real value">
    If you rename a field in the base type, Partial/Pick/Omit propagate automatically — manual types silently break.
  </Step>
</Steps>
